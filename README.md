# Mi primer portafolio con Kiro

Una página web personal que haces tuya en una hora. Trae portada animada, modo oscuro, tarjetas que se voltean, una sección para tus proyectos de GitHub y misiones que se van palomeando solas conforme la personalizas.

Funciona en tu computadora con doble clic: no necesitas internet, instalar nada más ni tener cuenta de AWS.

## Descárgala (no necesitas cuenta)

1. En esta página, toca el botón verde **Code** y elige **Download ZIP**.
2. Busca el archivo en tu carpeta de Descargas, dale **clic derecho → Extraer todo**.
3. Entra a la carpeta que se creó. Ahí están todos los archivos.

Si abres `index.html` y se ve sin colores, es que lo abriste dentro del ZIP: primero hay que extraerlo.

## Empieza en 3 pasos

1. **Ábrela.** Haz doble clic en `index.html`. Se abre en tu navegador con datos de ejemplo.
2. **Hazla tuya.** Abre esta carpeta en Kiro (`Archivo → Abrir carpeta`) y pídele en el chat lo que quieras cambiar. Por ejemplo:
   > Cambia mi nombre a Ana, pon de avatar un 🎸 y usa colores morado y amarillo.
3. **Mírala.** Guarda y recarga la página en el navegador (tecla `F5`).

## Sube de nivel

Toca el botón **🎯 Misiones** en la esquina de la página. Te dice qué falta y qué pedirle a Kiro. Cada vez que recargas, revisa tus datos y palomea lo que ya hiciste:

🌱 Principiante → 🧭 Explorador → 🔧 Constructor → ⚡ Casi Builder → 🏆 Builder

¿Sin ideas? En [`PROMPTS.md`](PROMPTS.md) hay peticiones listas para copiar. ¿Ya eres Builder? Sigue con los 15 retos de [`RETOS.md`](RETOS.md).

**¿Ya programas o tienes proyectos en GitHub?** En el mismo panel hay 6 misiones avanzadas ⭐: mostrar tus repositorios, crear secciones y funciones nuevas, y publicar tu portafolio con GitHub Pages. Complétalas todas y llegas a 🚀 Súper Builder.

## Qué hay en la carpeta

| Archivo | Para qué sirve |
|---|---|
| `datos.js` | **Tus datos.** Nombre, frase, intereses, metas y colores. |
| `index.html` | La estructura de la página. |
| `estilos.css` | El diseño y las animaciones. |
| `app.js` | Dibuja tus datos en la página. |
| `misiones.js` | El panel de misiones. |
| `.kiro/steering/` | Las reglas que Kiro sigue en este proyecto. |

## También puedes editar a mano

Abre `datos.js` y cambia el texto que está entre comillas. Tres reglas para no romper nada:

1. El texto va entre comillas: `"así"`.
2. Cada renglón termina con coma.
3. No borres las llaves `{ }` ni los corchetes `[ ]`.

Si la página queda en blanco o sale un aviso rojo, falta una comilla o una coma. Pídele a Kiro: «Revisa datos.js y corrige el error».

## Cuida tu privacidad

Usa tu nombre de pila o un apodo y un emoji como avatar. No pongas teléfono, dirección ni datos de tu familia.
